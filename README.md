# EMET8014

Course materials for EMET4314/8014 (Advanced Econometrics I) at ANU.

**Live site:** https://juergenmeinecke.github.io/EMET8014/

## Julia Notebooks

All Julia notebooks are in the `computer_labs/` and `assignments/` directories.

## Getting Started: Julia, Jupyter and VS Code

We recommend installing Julia and VS Code on your own computer — detailed instructions are on the
[live site](https://juergenmeinecke.github.io/EMET8014/). Your workflow is then simply to open VS
Code and work on the relevant notebooks. All your work is saved locally on your machine.

## Alternative: GitHub Codespaces

If you prefer not to install anything locally, you can use GitHub Codespaces — essentially VS Code
running in the cloud. We've configured the repository so that everything is ready to go. Click the
button below to launch a Julia + Jupyter environment in your browser:

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://github.com/codespaces/new?repo=juergenmeinecke/EMET8014)

All required Julia packages are pre-installed — just open a notebook and start working.

> **Note:** The first time you create a codespace it takes about 5 minutes to set up the
> environment. Subsequent launches are much faster.

> **Cost:** GitHub Codespaces comes with a limited number of free compute hours each month. Beyond
> that, you may be charged. We recommend signing up for the [GitHub Student Developer
> Pack](https://education.github.com/pack), which provides a free allowance that should
> comfortably cover everything you need for this course.
